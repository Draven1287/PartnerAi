# Learning AI V1 To V2 Product Plan

Date: 2026-05-24

## Big Direction

Learning AI should become an interactive 30-lesson course that takes someone from not knowing what AI is to using AI with judgment and building useful workflows, tools, and projects.

The current public site should not try to become the full course immediately. V1 should become a strong preview of V2:

- show the mission
- show the 30-lesson direction
- let people try the assessment
- preview the learning style
- collect friend feedback
- make people want the full V2

V2 should be built locally first, tested, then pushed as a major update.

## V1 Product Role

V1 is the preview and trust builder.

V1 should answer:

- What is Learning AI?
- Who is it for?
- What will V2 teach?
- How will it be different from boring AI lessons?
- Why should someone come back?
- What can I try today?

V1 should not pretend to be the full 30-lesson product.

### 3. Add The 30-Lesson Syllabus Preview

Add a readable version of the master syllabus to the site, but not as a giant wall of text.

Better format:

- six arc cards
- each arc expands to show lessons
- each lesson has one-line purpose

### 4. Improve Assessment Personalization

Replace or improve age-only setup with learner stage and goals.

Suggested profile questions:

- Are you in early high school, late high school, college, adult beginner, educator, or builder?
- What do you want AI to help you with most?
- What do you want to take away from this site?
- How do you like learning?
  - quick examples
  - step-by-step
  - visuals
  - projects
  - challenge me
- How comfortable are you with AI right now?
  - nervous
  - curious
  - using it sometimes
  - confident
  - building with it

Keep free-response optional. Do not make the assessment feel like a school form.

### 5. Add One Sample Interactive Activity

V1 needs one activity that proves the future product will not just be reading.

Best candidate:

`Bad Tutor vs Good Tutor`

Learner sees two AI study responses:

- one gives the answer and kills learning
- one gives hints, asks questions, and checks understanding

Learner chooses which protects learning and then builds a Study Coach Card.

This connects directly to the first V2 slice.

## V2 Product Shape

V2 should be a real learning app, not just more pages.

Core mechanics:

- 30-lesson path
- Foundation / Explorer / Builder level variants
- Student / Teacher / Builder / Business / Creative tracks
- My AI Toolkit
- progress and checkpoints
- interactive lesson activities
- capstone project
- builder gallery later

## V2 Membership Idea

The $10/month idea can work, but the free/paid line matters.

Recommended free:

- intro assessment
- V1 preview lessons
- full 30-lesson core course, if possible
- basic progress tracking
- sample Study Coach activity
- starter projects and templates
- curated public featured builds

Recommended paid:

- Builder Club membership after or during the course
- ability to publish builds to the member gallery
- full "how it was built" breakdowns
- monthly builder challenges
- member-only remix templates
- saved build portfolio/profile
- structured peer feedback
- badges or certificates for shipped builds and challenges
- future advanced builder labs

Important:

Do not make the course feel like a trap. The strongest model is:

> Learn for free. Pay when you want to keep building with structure, examples, challenges, and a portfolio.

If the full 30 lessons must be paid later, do not make accounts/payments part of the first V2 learning prototype. Validate the learning loop first.

## Post-Course Engagement

After the 30 lessons, learners are Builders.

Good post-course loops:

- Build Month 1 after lesson 30
- monthly builder challenges
- project gallery
- "how I built this" breakdowns
- remixable project templates
- AI workflow library
- student showcase
- peer feedback
- capstone upgrades
- advanced labs
- office-hours/cohort later

Builder gallery rules:

- shared projects must include what it does
- what AI helped with
- prompt/workflow summary
- what the human checked
- what could fail
- how someone can remix it
- no personal information
- no open DMs between students
- submissions start pending/private until approved
- structured reactions before open comments

This keeps the gallery educational, not just a brag wall.

## Interactivity Standard

The site should not rely on reading.

Every lesson should include at least one of:

- choose the better AI response
- repair a bad prompt
- compare outputs
- spot the hallucination
- sort safe vs unsafe uses
- build a toolkit card
- make a workflow map
- score an AI answer with a rubric
- revise and try again

Visual effects should support learning, not decorate the page.

Good visual effects:

- progress map
- animated arc path
- expanding lesson cards
- side-by-side comparison
- drag/sort cards
- token/pattern visualizer
- toolkit card builder
- prompt transformation animation
- confidence/skill meter tied to actual checks
- lightweight confetti only on meaningful milestones

Avoid:

- heavy animations
- distracting backgrounds
- gamification that hides the learning
- fake AI simulation that misleads users

## Recommended Build Order

1. Finish V1 preview updates.
2. Push V1.
3. Build V2 locally as a separate prototype.
4. Start with Student Study Coach slice.
5. Test with friends/students.
6. Expand to 12-lesson core.
7. Expand to 30 lessons.
8. Add backend/member features only after the learning loop works.

## Assessment Personalization Upgrade

The assessment should feel like it changes the learning path, not just scores a quiz.

Recommended V1/V2 fields:

- learner stage:
  - early high school
  - late high school
  - college
  - adult beginner
  - educator
  - builder
- primary goal:
  - learn/study
  - write/research
  - build/code
  - save time
  - create
  - teach/help others
  - understand AI safely
- AI confidence:
  - nervous
  - curious
  - tried it a little
  - use it often
  - want advanced building
- learning style:
  - quick examples
  - step-by-step
  - visuals
  - projects
  - challenge me
- main concern:
  - accuracy
  - privacy
  - cheating/ethics
  - job impact
  - creativity
  - not sure

Free-text should be used visibly or clearly labeled as feedback. Do not pretend free-text changes the path if it only gets saved locally.

## Recommended V1 Scope After Subagent Review

Make V1 do four things well:

1. Explain that the current five lessons are preview lessons.
2. Show the bigger V2 promise clearly.
3. Make assessment fields match the future V2 model.
4. Add one real sample interaction, preferably `Bad Tutor vs Good Tutor`.

Do not build in V1:

- accounts
- payment
- embedded chatbot
- real gallery submissions
- teacher dashboard
- full 30 lessons
- separate lesson variants for every level and track
- advanced agents or voice workflows

## Best Paid Product Direction

Recommended paid product name:

`Learning AI Builder Club - $10/month`

Paid promise:

> After the course, keep shipping real AI projects every month.

This is stronger than:

> Pay to see a gallery.

The paid value should be structure, challenges, breakdowns, remix templates, portfolio, and feedback.
