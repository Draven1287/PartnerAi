How to use this course

If you are new, take the gauge first. It checks knowledge and judgment, then changes how the course talks to you.

If you already know the basics, still start at Chapter 1. For you, the early chapters act like calibration before harder work.

Build as you go. Reading about AI is not enough. You need to test prompts, compare answers, catch mistakes, and finish small projects.
